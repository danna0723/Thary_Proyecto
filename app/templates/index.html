Columnas que reconoce el archivo

El sistema acepta encabezados en español o en inglés — no hace falta que el archivo tenga un formato exacto, solo que use alguno de estos nombres.

Obligatorias — sin estas columnas el archivo no se puede procesar

Fecha / Date / Sale_Date Fecha de la venta
Código / Code / Id Código del producto
Cantidad / Quantity / Demanda / Demand Unidades vendidas

Opcionales — si faltan, el sistema sigue funcionando, pero sin la función que dependa de ellas

Producto / Product / Nombre_Producto / Product_Name Nombre del producto
Categoria / Category Categoría del producto
Inventario_Actual / Inventory / Stock Unidades disponibles en inventario (activa las alertas de pedido)
Precio / Price / Unit_Price Precio de venta (mejora el pronóstico y permite calcular el costo de ruptura)
Costo_unitario Costo de compra por unidad (para estimar costos y limitar el pedido según el presupuesto)
Costo_pedido, Porcentaje_costo_mantenimiento Costo de hacer un pedido y de mantener el inventario (con el costo unitario, permiten calcular el pedido óptimo, EOQ)
Lead_time_Semana / Lead_time / Tiempo de entrega Tiempo de entrega del proveedor, en semanas (si falta, se asumen unas 2 semanas)
Proveedor / Supplier, Proveedor_Alterno Proveedor principal y alterno, para elegir a quién pedirle al confirmar un pedido
