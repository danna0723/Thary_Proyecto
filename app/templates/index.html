Aparece en el sidebar y en el reporte de demanda descargable. Opcional.
Se reparte en partes iguales entre todos los productos activos del catálogo y limita cuánto se sugiere pedir de cada uno. Si no lo cambias, se usa $500.000 como valor por defecto.
Por ejemplo, poné 3 para ver los próximos 3 meses, o 12 para ver todo el año que viene. Si querés ver un mes puntual (como diciembre), poné la cantidad de meses que faltan hasta ese mes — va a aparecer como una de las columnas del resultado. Como el pronóstico se calcula mes a mes en cadena, entre más meses pidas, más se puede acumular el error hacia el final del horizonte.

Columnas que reconoce el archivo

El sistema acepta encabezados en español o en inglés — no hace falta que el archivo tenga un formato exacto, solo que use alguno de estos nombres.

Obligatorias — sin estas columnas el archivo no se puede procesar.

Fecha / Date / Sale_Date Fecha de la venta o movimiento
Producto / Product / Product_ID Identificador del producto
Demanda / Demand / Sales / Quantity_Sold Cantidad vendida

Opcionales — si faltan, el sistema sigue funcionando, pero sin la función que dependa de ellas.

Nombre_Producto / Product_Name Nombre legible del producto en las pantallas
Categoria / Category Agrupa los productos por categoría
Inventario_Actual / Inventory / Stock Habilita las alertas de reposición y el valor del inventario
Precio / Price / Unit_Price Se usa como variable del pronóstico
Costo_unitario Costos estimados y límite del presupuesto por producto
Costo_pedido, Porcentaje_costo_mantenimiento Junto con el costo unitario, habilitan el cálculo de EOQ
Lead_time_Semana Tiempo de entrega real del proveedor (si falta, se usa un valor por defecto)
Proveedor / Supplier, Proveedor_Alterno Para elegir a quién pedirle al confirmar un pedido
